# jet-icons M1 — Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SVG/PNG logodan, tek ortak tasarım + platform override'larıyla altı platformun (iOS, Android, macOS, Windows, Web/PWA, Linux) app icon setini üretip zip/klasör olarak dışa aktaran masaüstü uygulaması.

**Architecture:** Pub workspace monorepo. `packages/jet_icons_core` saf Dart (model, `.jeticon` codec, override çözümleme, platform çıktı tabloları, kodlayıcılar, içe aktarıcılar, dışa aktarma hattı, `IconRasterizer` arayüzü). `packages/jet_icons_render` Flutter (`dart:ui` ile çizim + PNG; tuval, önizleme ve dışa aktarma aynı `IconPainter`'ı kullanır). `app` Flutter masaüstü uygulaması (Tasarla / Platformlar / Dışa aktar sekmeleri).

**Tech Stack:** Flutter 3.50 / Dart 3.14, pub workspaces, `xml`, `archive`, `image` (core); `path_parsing`, `flutter_svg` (render); `file_selector` (app); `test`, `flutter_test`.

**Spec:** `docs/superpowers/specs/2026-11-19-jet-icons-design.md` — §7, §8 ve §9/M1 bu planın kaynağı. Uygulayıcı ikisini birlikte okur.

## Global Constraints

- Lisans Apache 2.0; eklenen her bağımlılık Apache/MIT/BSD uyumlu olmalı.
- `jet_icons_core` Flutter'a bağımlı olamaz (`dart:ui`, `package:flutter` import yok) — gelecekteki CLI ve alternatif rasterizer bunu kullanacak.
- Tasarım tuvali 1024×1024 birim; tüm transform'lar bu birimde.
- `.jeticon`: JSON, 2 boşluk girintili, sabit anahtar sırası, renkler `"#AARRGGBB"`; `formatVersion: 1`; bilinmeyen üst-seviye alanlar okunup yazılırken korunur.
- Tam SVG desteği dışlanmaz: uyumsuz SVG reddedilmez, `RawSvgElement` olarak saklanır; rasterizer arayüz arkasında.
- Proje / zip dışı hiçbir dosya sessizce ezilmez (spec §4).
- M1 uygulama platformları: macOS, Windows, Linux (mobil M4).
- Çıktı yolları zip/klasör içinde platform klasörlerine ayrılır: `ios/`, `android/`, `macos/`, `windows/`, `web/`, `linux/`.

## Review Focus

1. **viewBox'sız veya birimli (`width="24px"`) SVG** — doğru boyutla içe aktarılmalı (Task 5'te test).
2. **Bozuk ya da daha yeni `formatVersion`'lı `.jeticon`** — açık hata mesajı, çökme yok, açık doküman değişmez (Task 1 ve Task 8'de test).
3. **Silinmiş öğeye işaret eden override yaması** — yok sayılır, çözümleme çökmez (Task 2'de test).
4. **Dolu bir klasöre dışa aktarma** — onaysız üzerine yazma yok (Task 6'da test).
5. **Şeffaf logo + opak olması gereken çıktı** (iOS açık, Play 512, apple-touch) — PNG'de alfa kanalı olmamalı (Task 3 ve Task 6'da test).

**Interfaces — Produces** (hepsi immutable, `==`/`hashCode` değer eşitliği, `copyWith`):
- `class JColor { final int argb; const JColor(this.argb); String toHex(); static JColor parse(String hex); }` — `parse` `#RGB`, `#RRGGBB`, `#AARRGGBB` kabul eder.
- `class Transform2D { final double a,b,c,d,e,f; static const identity; Transform2D multiply(Transform2D o); static Transform2D translate(double x,double y); static Transform2D scale(double sx,[double? sy]); static Transform2D rotate(double radians); }`
- `sealed class Fill` → `SolidFill(JColor color)`, `LinearGradientFill(List<GradientStop> stops, double x1,y1,x2,y2)`, `RadialGradientFill(List<GradientStop> stops, double cx,cy,r)`; `class GradientStop(double offset, JColor color)`. Koordinatlar tuval biriminde.
- `class Stroke(JColor color, double width)`
- `sealed class IconElement { String id; String name; Transform2D transform; double opacity; bool hidden; }` →
  - `PathElement(String d, Fill? fill, Stroke? stroke)` — `d` SVG path verisi.
  - `GroupElement(List<IconElement> children)`
  - `RasterElement(Uint8List png, int width, int height)`
  - `RawSvgElement(String svg, double vbX, double vbY, double vbWidth, double vbHeight)`
- `enum LayerKind { background, foreground, monochrome }`
- `class Layer(Fill? fill, List<IconElement> elements, double scale = 1.0)` — `scale`: içerik ölçeği, tuval merkezine göre (padding override'ı bununla yapılır). `fill` tüm alanı kaplar.
- `enum IconPlatform { ios, android, macos, windows, web, linux }`
- `enum IconVariant { light, dark, tinted }`
- `enum IconShape { roundedSquare, square, circle, none }` — `none` = arka plansız (yalnızca ön plan).
- `class SizeRange(int minPx, int maxPx)` — kapsayıcı; `bool contains(int px)`.
- `class LayerPatch(LayerKind layer, {double? scale, Fill? fill, bool? hidden})`
- `class ElementPatch(String elementId, {bool? hidden, double? opacity, Fill? fill, Transform2D? transform})`
- `class PlatformOverride(IconPlatform platform, {IconVariant? variant, SizeRange? sizeRange, List<LayerPatch> layerPatches = const [], List<ElementPatch> elementPatches = const [], Map<LayerKind, Layer> detached = const {}})`
- `class IconDocument(Layer background, Layer foreground, Layer? monochrome, Map<IconPlatform, IconShape> shapes, List<PlatformOverride> overrides, Map<String, Object?> extra)` — `monochrome == null` → ön plandan türetilir. `shapes` yalnızca `windows`, `linux`, `web` anahtarlarını kullanır; eksik anahtar = `roundedSquare`. `static IconDocument empty()` → arka plan `SolidFill(#FFFFFFFF)`, boş ön plan.
- `const int canvasSize = 1024; const int currentFormatVersion = 1;`
- `String encodeJeticon(IconDocument doc)`; `IconDocument decodeJeticon(String source)` — hata: `JeticonFormatException(String message)` (geçersiz JSON, eksik zorunlu alan, `formatVersion > currentFormatVersion`).

JSON şeması (anahtar sırası bu):
```json
{
  "formatVersion": 1,
  "canvasSize": 1024,
  "background": {"fill": {"type": "solid", "color": "#FFFFFFFF"}, "scale": 1.0, "elements": []},
  "foreground": {"fill": null, "scale": 1.0, "elements": [
    {"type": "path", "id": "e1", "name": "Logo", "d": "M0 0L10 0Z",
     "fill": {"type": "linear", "x1": 0, "y1": 0, "x2": 1024, "y2": 1024,
              "stops": [{"offset": 0, "color": "#FF4F7CFF"}, {"offset": 1, "color": "#FF8A5CFF"}]},
     "stroke": null, "transform": [1, 0, 0, 1, 0, 0], "opacity": 1.0, "hidden": false}
  ]},
  "monochrome": null,
  "shapes": {"windows": "roundedSquare", "linux": "roundedSquare", "web": "roundedSquare"},
  "overrides": [
    {"platform": "android", "variant": null, "sizeRange": null,
     "layerPatches": [{"layer": "background", "scale": null, "fill": {"type": "solid", "color": "#FF000000"}, "hidden": null}],
     "elementPatches": [], "detached": {}}
  ]
}
```
Öğe tipleri: `"path"`, `"group"` (`children`), `"raster"` (`png` base64, `width`, `height`), `"rawSvg"` (`svg`, `viewBox: [x,y,w,h]`). Fill tipleri: `"solid"`, `"linear"`, `"radial"` (`cx`,`cy`,`r`,`stops`). Ortak alanlar: `id`, `name`, `transform`, `opacity`, `hidden`.

**Files:**

- Consumes: Task 1 modeli.

Çözümleme kuralları (spec §7.1):
1. Başlangıç: `doc.background`, `doc.foreground`, `doc.monochrome ?? doc.foreground`.
2. `variant == dark` ise başlangıç arka planı `Layer(fill: null, elements: [])` olur (koyu varyant varsayılanı: şeffaf zemin).
3. Eşleşen override'lar şu sırayla uygulanır: (a) `platform` eşit, `variant == null`, `sizeRange == null`; (b) `platform` eşit, `variant == variant`, `sizeRange == null`; (c) `platform` eşit, `variant` null veya eşit, `sizeRange.contains(sizePx)`. Aynı gruptaki override'lar liste sırasıyla.
4. Her override'da önce `detached[kind]` varsa o katman tamamen değiştirilir, sonra `layerPatches`, sonra `elementPatches` (öğe id'si katmanlarda ve grup çocuklarında derinlemesine aranır; bulunamazsa yama yok sayılır). `LayerPatch.hidden == true` → katman `Layer(fill: null, elements: [])`.

### Task 3: Kodlayıcılar

**Files:**
- Create: `packages/jet_icons_core/lib/src/encoders/{ico.dart,icns.dart,contents_json.dart,adaptive_icon_xml.dart,web_manifest.dart,png_alpha.dart}`
- Test: `packages/jet_icons_core/test/encoders/*_test.dart`

**Interfaces — Produces:**
- `Uint8List encodeIco(List<(int size, Uint8List png)> images)` — PNG gömülü ICO. Header LE: reserved 0, type 1, count. Dizin girişi 16 bayt: width/height u8 (256 → 0), colors 0, reserved 0, planes 1, bitCount 32, bytesInRes u32, offset u32.
- `Uint8List encodeIcns(Map<int, Uint8List> pngBySize)` — big-endian; `'icns'` + toplam uzunluk; girişler `type(4) + length(u32, 8 bayt başlık dahil) + png`. Tip eşlemesi: 16→`icp4`, 32→`icp5` ve `ic11`, 64→`icp6` ve `ic12`, 128→`ic07`, 256→`ic08` ve `ic13`, 512→`ic09` ve `ic14`, 1024→`ic10`.
- `String iosContentsJson()` — Xcode tek-boyut formatı:
  ```json
  {"images":[
    {"filename":"AppIcon-1024.png","idiom":"universal","platform":"ios","size":"1024x1024"},
    {"appearances":[{"appearance":"luminosity","value":"dark"}],"filename":"AppIcon-1024-dark.png","idiom":"universal","platform":"ios","size":"1024x1024"},
    {"appearances":[{"appearance":"luminosity","value":"tinted"}],"filename":"AppIcon-1024-tinted.png","idiom":"universal","platform":"ios","size":"1024x1024"}
  ],"info":{"author":"jet-icons","version":1}}
  ```
- `String macosContentsJson()` — `{"idiom":"mac","scale":"1x|2x","size":"NxN","filename":"app_icon_P.png"}` 10 giriş.
- `String adaptiveIconXml({required bool includeMonochrome})` — `<adaptive-icon>` + `@mipmap/ic_launcher_background`, `@mipmap/ic_launcher_foreground`, `@mipmap/ic_launcher_monochrome`.
- `String webManifestIcons()` — `{"icons":[...]}`: Icon-192/512 `purpose: "any"`, maskable-192/512 `purpose: "maskable"`, `type: "image/png"`.
- `Uint8List stripAlpha(Uint8List png)` — `package:image` ile decode, RGB (3 kanal) olarak yeniden PNG kodla.
